## 三个下游坑

- 坑1 放宽重查（`entity_filter_relaxed=True`）：**0 条** —— 这些条的出口看着像正常命中，实质靠拆掉实体过滤才召回到内容，判读时按裸搜算
- 坑2 固定话术：零证据 0 条 / 检索未完成 0 条 / 生成失败 0 条 / 带放宽说明 0 条 —— 零证据≠认错款，两类修法不同，不能合并
- 坑3 话题一致性校验（目标轮）：换入 0 条 / 未动作 1 条 / 仅记录 0 条 / 无日志 11 条 —— 换入过的条，最终答案与出口标记不同源
  前置轮另记：换入/仅记录共 0 次 —— 前置轮动过窗口就意味着喂给目标轮的历史文本已被改过，不能当噪音扔
  「无日志」不等于没跑校验：四条文案都在「有专名可对齐」时才写，判据不足以外走不到分支就没行
